Lo que vamos a usar

La recta, con b = 0

$$\hat y^{(i)} = w\,x^{(i)}$$

Para simplificar, fijamos $b = 0$ y solo movemos $w$, el precio por kilo. Con 0 kilos se pagan 0 pesos.

El costo

$$J(w) = \frac{1}{2m}\sum_{i=1}^{m}\big(\hat y^{(i)} - y^{(i)}\big)^2$$

Se lee: "para cada ticket, predicción menos respuesta, al cuadrado; se suman; se divide entre dos veces el número de tickets". Ojo: $J$ no está en pesos, está en pesos al cuadrado. Sirve para comparar rectas: la de menor $J$ gana.
